# 실습 노트북

주차별 실습 노트북. 각 노트북 상단의 Colab 배지로 바로 열린다.

## 표준 형태

`_template.ipynb` 를 따른다. `make new-notebook N=03` 으로 생성한다.

1. Colab 배지
2. 목표 한 줄
3. 그냥 실행하면 되는 셀들 - 학생이 먼저 성공을 확인하는 구간
4. **`# TODO` 한 곳** - 수업계획서 [구현]이 지정한 그 지점 하나만
5. 확인 질문 2~3개
6. 제출 안내

## 원칙

- **TODO를 건드리지 않은 상태로도 위에서 아래로 끝까지 실행돼야 한다**
- Colab 무료 티어에서 도는 규모로 잡는다
- 데이터는 저장소에 담지 않고 다운로드 셀로 처리한다
- 밑바닥부터 작성하게 하지 않는다. 골격은 항상 제공한다
