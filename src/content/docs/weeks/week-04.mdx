## 이번 주차

숨겨진 마르코프 모델(HMM)과 시퀀스 태깅

## 온라인 (2시수)

HMM 구성요소, 품사 태깅 문제, 비터비 알고리즘 개념 강의 / 학습활동 - 한국어 문장 1개의 품사를 직접 붙여 보고 애매한 지점 표시

## 대면 (1시수)

형태소 분석기 적용, 예측 결과 분석

## 학습활동

**[이론]** 알고리즘 내부 구현은 다루지 않고 **동작 결과 해석에 집중**. 사람이 애매하다고 느낀 지점과 모델이 틀린 지점을 대조

**[구현]** 형태소 분석 라이브러리를 적용해 결과를 뽑고, 자신이 붙인 품사와 비교

**[실무]** 한국어 형태소 분석의 난점(조사 분리·중의성)을 실제 오류 사례로 확인. **방언 표현을 형태소 분석기에 넣어 어떻게 처리되는지 관찰**하고, 아래아(ㆍ) 같은 표기 문제는 **현상 소개까지만** 다룸
