## 이번 주차

문장 임베딩과 텍스트 유사도

## 온라인 (2시수)

문장·문서 벡터화, TF-IDF, 문장 임베딩 모델 개요 강의 / 학습활동 - 같은 뜻 다른 표현 문장쌍 3개를 만들어 제출

## 대면 (1시수)

TF-IDF 기반 문서 검색, 문장 유사도 측정, 간단한 검색 엔진 구축 실습

## 학습활동

**[이론]** 단어 단위 유사도와 문장 단위 유사도의 차이를 학생이 만든 문장쌍으로 확인

**[구현]** 간단한 문서 검색기를 데모 따라 구축하고 자신이 만든 문장쌍으로 검증

**[실무]** 검색 결과가 기대와 다를 때 무엇을 고칠 수 있는지 정리. **관광 정보 검색에서 같은 질문을 다르게 물었을 때** 결과가 갈리는 사례로 확인. 중간 프로젝트 주제 안내
