과제는 이 저장소에 **Pull Request**로 제출한다.

<Aside type="tip" title="설치할 것이 없다">
GitHub 웹사이트에서만 해도 제출이 끝난다. git 명령어나 Node를 설치하지 않아도 된다.
</Aside>

## 처음 한 번만

<Steps>
1. [github.com](https://github.com) 에서 계정을 만든다
2. 이 저장소 오른쪽 위 **Fork** 를 누른다
</Steps>

## 매번 제출할 때

<Steps>
1. Colab에서 작업한 노트북을 **파일 > .ipynb 다운로드** 로 내려받는다
2. 내 Fork 저장소에서 `assignments/week-01/` 로 들어간다 (주차에 맞게)
3. **Add file > Upload files** 를 누르고 내려받은 파일을 끌어다 놓는다
4. 경로를 `assignments/week-01/<내 학번>/` 이 되도록 적는다
5. **Commit changes** 를 누른다
6. **Contribute > Open pull request** 를 누른다
7. PR 제목을 `[제출] 1주차 - 20260001 홍길동` 형식으로 적고 연다
</Steps>

## 폴더 규칙

```
assignments/
  week-01/
    20260001/          <- 학번만. 이름은 넣지 않는다
      week-01.ipynb
```

- 폴더 이름은 **학번만** 쓴다. 이름은 PR 제목에만 적는다
- 다른 사람 폴더는 건드리지 않는다

## 확인

PR을 열면 자동 검사가 돈다. 초록색 체크가 뜨면 제출된 것이다.
빨간색이 뜨면 폴더 이름이 규칙과 다를 가능성이 높으니 경로를 다시 본다.

<Aside type="caution" title="공개 저장소다">
이 저장소는 공개다. 제출물에 개인정보(연락처, 주민번호 등)를 넣지 않는다. 학번까지만 쓴다.
</Aside>
