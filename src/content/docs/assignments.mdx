과제는 이 저장소에 **Pull Request**로 제출한다.

<Aside type="tip" title="설치할 것이 없다">
GitHub 웹사이트에서만 해도 제출이 끝난다. git 명령어나 Node를 설치하지 않아도 된다.
</Aside>

## 처음 한 번만

<Steps>
1. [github.com](https://github.com) 에서 계정을 만든다
2. 이 저장소 오른쪽 위 **Fork** 를 누른다
</Steps>

## 매번 제출할 때

<Steps>
1. Colab에서 실행한 노트북을 **파일 > .ipynb 다운로드** 로 내려받는다. 12·13·15주차는 해당 주차의 제공 양식으로 작성한 파일을 준비한다
2. 내 Fork 저장소에서 **Sync fork > Update branch** 로 강의 자료를 갱신한다. 내 제출 파일이 남아 있는지도 확인한다
3. 이번 주차의 내 학번 폴더가 없으면 **Add file > Create new file** 에서 파일명을 `assignments/week-01/20260001/README.md`처럼 적는다. 주차와 학번은 내 것으로 바꾸고, 본문에 `1주차 제출`을 적어 **Commit changes** 를 누른다
4. 내 학번 폴더 안에서 **Add file > Upload files** 를 눌러 준비한 파일을 올리고 **Commit changes** 를 누른다
5. **Contribute > Open pull request** 를 누른다. 제출 대상이 `halla-ai/intronlp-2026`의 `main`인지 확인한다
6. PR 제목은 `[제출] 1주차 - 20260001`처럼 주차와 학번만 적는다
7. **Files changed** 에 이번 과제의 내 학번 폴더만 있는지 확인하고 PR을 연다

</Steps>

## 폴더 규칙

```
assignments/
  week-01/
    20260001/          <- 학번만. 이름은 넣지 않는다
      week-01.ipynb
```

- 폴더 이름은 **학번만** 쓴다. PR 제목에도 이름·연락처를 넣지 않는다
- 다른 사람 폴더는 건드리지 않는다

## 확인

PR을 열면 제출 기록이 남고, 자동 검사는 파일 경로와 PR 제목 형식을 확인한다. 초록색 체크는 형식 검사 통과이며 교수자의 접수·채점·성적 확정은 별도다.
빨간색이 뜨면 검사 로그를 보고 PR 제목 형식 또는 파일 경로를 확인한다. 제목을 고치면 검사가 다시 실행된다.

<Aside type="caution" title="공개 저장소다">
이 저장소는 공개다. 제출물에 개인정보(연락처, 주민번호 등)를 넣지 않는다. 학번까지만 쓴다.
</Aside>
